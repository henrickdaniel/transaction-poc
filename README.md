# Transaction POCs - Spring Boot & Spring Data JPA

Repositório contendo provas de conceito (POCs) cobrindo diferentes cenários de gerenciamento de transações com `@Transactional`, testes de integração e estratégias de isolamento para CI/CD.

## 📂 Subprojetos

1. **`basic-transaction-poc`**: Demonstração fundamental do `@Transactional` com rollback automático usando PostgreSQL local via Docker.
